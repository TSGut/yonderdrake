# Time-memory theory

The supported time derivatives and their memory representations are described
on the pages below. Power-law memory uses either stored history or diffusive
modes. Single-exponential memory is a bounded-kernel fading-memory operator
with one exact state and no quadrature spectrum. It shares the time-memory
interface.

How those modes are advanced alongside the field is a separate choice, covered
in {doc}`time-stepping`.
