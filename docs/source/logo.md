# Logo

```{image} _static/yonderdrake-logo.png
:alt: The Yonderdrake logo, a dragon drawn in a viridis-like colour scheme
:width: 320px
:align: center
```

The logo nods to the *long memory* of time-fractional operators: a fractional
derivative still feels the entire history that preceded it.

The dragon is inspired by the
[Lindwurmbrunnen](https://www.atlasobscura.com/places/lindwurmbrunnen) in
Klagenfurt, Austria, drawn in a viridis-like colour scheme to match the
default palette used throughout the {doc}`gallery <gallery/index>`.

The logo and the favicon are committed at `docs/source/_static/`:

| File | Use |
| --- | --- |
| `yonderdrake-logo.png` | Sidebar logo (`html_logo`) and the README header |
| `yonderdrake-favicon.png` | Browser tab icon (`html_favicon`) |

Both are released under the same MIT License as the rest of the project.
