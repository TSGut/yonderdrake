# Contributing

Contributions to Yonderdrake are welcome. Numerical changes should include:

- the operator definition and a primary reference
- the implementation
- tests that isolate different errors (e.g. representation, discretization, quadrature)
- explicit validation
- a demo

Issues are also welcome requesting support for relevant operators or
alternative numerical methods from the literature. Include a primary
reference and a representative problem where possible.

LLM-assisted contributions are welcome in principle and are held to the same
standards as all others. The human author remains responsible for the code they
submit.
